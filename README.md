# 🌾 Harvest Prediction Agent

An AI-powered agent for predicting harvest dates using agricultural,
environmental, and machine learning data.

## 🤖 About

This project is designed to automate the harvest-date prediction
process by working with agricultural and environmental data.

The agent can load feature data, process the available information,
perform feature engineering, and generate a harvest-date prediction.

## 🔄 Workflow

Input Data
↓
Data Loading
↓
Feature Engineering
↓
Machine Learning
↓
Harvest Date Prediction

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- LightGBM
- MinIO
- FastAPI
- Docker

## 🎯 Goal

The goal of this project is to create an automated prediction system
that can process agricultural data and estimate harvest dates.

## 👩‍💻 Development

This project was developed as an AI engineering project with
prompt-assisted development and iterative testing and debugging.
